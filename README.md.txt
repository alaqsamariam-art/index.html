# منصة تنسيق المساعدات الإنسانية في مدينة غزة بعد الحرب

## فكرة الموقع (Problem → Solution)
بعد الحرب على قطاع غزة، ظهرت الحاجة إلى تنظيم وتنسيق المساعدات الإنسانية بشكل أفضل،  
حيث تواجه المؤسسات والمتطوعون صعوبة في معرفة أماكن ونوع ووقت توزيع المساعدات.

جاءت فكرة هذا الموقع كحل رقمي يساعد على:
- عرض أنواع المساعدات المتوفرة
- تنظيم معلومات التوزيع
- تسهيل وصول المساعدات لمستحقيها
- تحسين التنسيق بين الجهات الإنسانية

-----------------------------------

## المستخدم المستهدف
- المؤسسات الإغاثية
- المتطوعون
- الأهالي المتضررون
- الجهات المهتمة بتنسيق المساعدات الإنسانية

-----------------------------------

## أهم الميزات
- تصميم متجاوب يعمل على الهاتف والتابلت والكمبيوتر
- عرض أنواع المساعدات (غذاء، دواء، مياه، إيواء)
- فلترة جدول التوزيع حسب المنطقة
- عرض تفاصيل المساعدات داخل نافذة Modal
- زر الوضع الداكن (Dark Mode)
- استخدام أيقونات توضيحية لتحسين تجربة المستخدم

------------------------------------

## التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- Font Awesome

-------------------------------------

## طريقة التشغيل
1. افتح ملف `index.html`
2. سيتم تشغيل الموقع مباشرة في المتصفح
